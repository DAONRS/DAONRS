DAONRS 정화 영향도 검증

저장된 게시글에 DOMPurify를 적용했을 때 무엇이 사라지는지만 확인합니다. DB에 쓰지 않고 읽기만 하며, 프로젝트 코드도 건드리지 않습니다.

1. 연결 정보

둘 다 브라우저에 이미 공개되는 값이라 여기 그대로 두셔도 됩니다. 공개 SELECT 권한만 사용합니다.

실행할 쿼리: select 'notices' t, id::text, title, content from notices union all select 'archives', id::text, title, content from archives union all select 'case_examples', id::text, title, content from case_examples; 결과를 JSON으로 내보내 붙여넣으면 됩니다.
